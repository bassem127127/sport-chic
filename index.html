Connectez votre projet Sport Chic à votre base de données Supabase. Saisissez vos identifiants ci-dessous pour activer le stockage dynamique en temps réel.

Structure de table SQL recommandée

Exécutez ce script SQL dans l'éditeur de requêtes Supabase (SQL Editor) pour configurer la table products avec les colonnes et les droits d'accès requis : 

CREATE TABLE products (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT NOT NULL,
  price NUMERIC NOT NULL,
  category TEXT NOT NULL,
  badge TEXT,
  rating NUMERIC DEFAULT 5.0,
  reviews INTEGER DEFAULT 0,
  image TEXT NOT NULL,
  specs JSONB NOT NULL,
  sizes JSONB NOT NULL,
  ar_name TEXT,
  ar_badge TEXT,
  ar_description TEXT,
  ar_specs JSONB
);

-- Activer Row Level Security
ALTER TABLE products ENABLE ROW LEVEL SECURITY;

-- Politiques d'accès public
CREATE POLICY "Lecture publique" ON products FOR SELECT USING (true);
CREATE POLICY "Insertion publique" ON products FOR INSERT WITH CHECK (true);
CREATE POLICY "Mise a jour publique" ON products FOR UPDATE USING (true);
CREATE POLICY "Suppression publique" ON products FOR DELETE USING (true);
